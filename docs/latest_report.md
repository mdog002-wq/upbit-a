# 암호화폐 퀀트 투자 분석 종합 리포트

본 리포트는 제공된 상위 20개 암호화폐의 정밀 퀀트 데이터를 바탕으로 작성되었습니다. 거래대금, 24시간 변동성, 그리고 과거 상승 패턴과의 유사도를 측정하는 골든패턴 점수를 종합하여 시장의 기회 요인과 위험 요인을 다각도로 분석했습니다.

## 2. 주요 지표별 동향
- **골든패턴 최고점 종목 (Score 100.0):** CAP, GRVT, ONG, PRL, EUL, UNI 종목들이 과거 강력한 상승 랠리 직전의 패턴과 100% 일치하는 수치를 기록했습니다.

골든패턴 유사도가 높으면서도 변동성이 상대적으로 안정적이거나 거래대금이 풍부한 종목을 중심으로 포트폴리오를 구성하는 것이 유리합니다. 과도한 변동성을 보이는 종목은 분할 매수 및 철저한 손절가 설정을 동반해야 합니다.
