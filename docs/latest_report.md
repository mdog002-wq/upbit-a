# 암호화폐 퀀트 투자 분석 종합 리포트

## 1. 개요
본 리포트는 제공된 상위 20개 종목의 정밀 퀀트 엔진 데이터(거래대금, 24시간 변동성, 골든패턴 유사도 점수)를 바탕으로 엄격하게 검증하여 최우선 추천 종목과 위험/주의 종목을 선별하였습니다. 시장의 과열 구간과 안정적인 반등 구간을 분리하여 리스크 관리에 만전을 기했습니다.

## 2. 퀀트 지표 분석 결과
- **골든패턴 유사도 (Golden Pattern Score)**: 100점 만점을 기록한 종목들(PRL, COW, LINK, ENSO, TREE, TT, WAL)은 역사적 바닥 매집 패턴과 매우 높은 일치율을 보이며, 반등 확률이 극대화된 상태입니다.
- **변동성 및 거래대금 (Volatility & Volume)**: 과도한 변동성을 보이는 종목은 단기 급등락에 따른 손실 위험이 있으므로 주의가 필요합니다.
