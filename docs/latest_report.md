# 암호화폐 퀀트 분석 리포트

## 1. 최우선 추천 종목 분석
골든패턴 유사도 점수 100.0점을 기록한 종목 중 거래대금과 변동성을 안정적으로 소화하며 반등 확률이 높은 종목을 선별했습니다. 특히 UNI(유니스왑)는 100점의 만점 패턴 유사도를 보이면서도 변동성이 10.88%로 상대적으로 통제되어 있어, 탄탄한 거래대금 기반의 안정적인 매집 후 반등이 기대됩니다.

## 2. 위험/주의 종목 분석
CAP 종목은 골든패턴 유사도 100.0점을 기록하였으나, 24시간 변동성이 50.82%에 달해 단기 과열 양상이 극심합니다. 급격한 시세 변동에 따른 휩소(Whipsaw) 위험이 매우 크므로 추격 매수를 엄격히 자제해야 합니다.
