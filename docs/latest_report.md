# 암호화폐 퀀트 분석 리포트

- **ONDO**: 변동성이 4.18%로 낮고 안정적이며, 골든패턴 점수 79.3점을 기록하여 하방 경직성이 확보된 우량 종목입니다.

## 3. 위험/주의 종목 분석
- **CAP**: 골든패턴 점수는 100점이나 24시간 변동성이 50.82%에 달해 단기 과열 및 극심한 가격 변동 리스크가 존재합니다.
