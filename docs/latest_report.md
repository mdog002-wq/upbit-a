# 퀀트 투자 분석 종합 리포트

## 1. 시장 개요 및 퀀트 엔진 분석 방향
본 리포트는 제공된 상위 20개 암호화폐 종목의 거래대금, 24시간 변동성, 골든패턴 유사도 점수를 기반으로 정밀 퀀트 분석을 수행했습니다. 시장 전반의 유동성과 패턴 적합도를 분석하여 최적의 투자 기회와 잠재적 리스크 요인을 도출했습니다.

## 2. 주요 종목 분석
- **MOVE (무브)**: 골든패턴 유사도 점수 87.0으로 매우 우수하며, 적정한 수준의 변동성과 강력한 거래대금을 동반하여 상승 추세 지속 가능성이 높습니다.
- **ONDO (온도)**: 골든패턴 유사도 80.7을 기록하였으며, 24시간 변동성이 4.18%로 낮아 안정적인 우상향 패턴을 보이는 모범적인 종목입니다.
- **CAP (캡)**: 골든패턴 유사도는 100.0으로 만점이나, 24시간 변동성이 50.82%에 달해 단기 과열 및 급등락 리스크가 매우 큽니다.
- **ONG (온고)**: 골든패턴 100.0점이지만 변동성이 31.64%로 높아 주의가 필요합니다.

## 3. 투자 전략 제언
안정적인 퀀트 투자를 위해 골든패턴 유사도가 높으면서도 변동성이 통제된 종목(MOVE, ONDO 등) 위주로 포트폴리오를 구성하고, 극단적인 변동성을 보이는 종목은 철저한 리스크 관리가 요구됩니다.
