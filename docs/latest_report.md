# 암호화폐 퀀트 분석 리포트

## 1. 시장 개요 및 퀀트 엔진 분석 방향
본 리포트는 제공된 상위 20개 코인의 거래대금, 24시간 변동성, 골든패턴 유사도 점수를 종합적으로 분석하여 최적의 투자 기회와 리스크 관리 구간을 도출했습니다. 골든패턴 유사도 점수와 적정 변동성을 기반으로 안정적인 반등 기대 종목을 선정하고, 단기 과열 구간에 진입한 자산에 대해서는 엄격한 주의를 당부합니다.

## 2. 주요 지표 분석
- **골든패턴 유사도**: 역사적 저점 매집 패턴과 가장 일치하는 종목(CAP, ONG, PRL, TT, LA, RVN)이 100.0점 또는 고득점을 기록했습니다.
- **변동성 및 리스크**: CAP 코인의 경우 24시간 변동성이 50.82%에 달해 기회와 동시에 높은 리스크를 동반하고 있습니다.

## 3. 투자 전략
- 안정성과 패턴 점수가 조화된 종목을 중심으로 분할 매수 접근.
- 과도한 변동성을 보이는 종목은 철저한 손절매 라인 설정 필요.
