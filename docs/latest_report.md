# 암호화폐 퀀트 투자 분석 리포트

## 1. 시장 개요 및 퀀트 엔진 분석 결과
본 리포트는 제공된 상위 20개 종목의 퀀트 데이터를 바탕으로 거래대금, 24시간 변동성, 골든패턴 유사도 점수를 종합적으로 분석하였습니다. 현재 시장은 주요 메이저 자산(BTC, ETH)의 안정적인 흐름 속에서 골든패턴 유사도 점수가 100점에 달하고 대규모 거래대금을 동반한 특정 알트코인들을 중심으로 강한 모멘텀이 포착되고 있습니다.

## 2. 최우선 추천 종목 선정 배경
- **ONG (온버프/ONG)**: 골든패턴 유사도 100점 만점을 기록하였으며, 72억 원 이상의 건실한 거래대금과 함께 23.97%의 적정 수준의 변동성을 보여주어 상승 랠리 초입의 매집 완료 구간으로 판단됩니다.
- **RVN (레이븐코인/RVN)**: 골든패턴 점수 100점과 더불어 8.18%의 안정적인 변동성을 기록하여 급등락 리스크를 최소화하면서도 확실한 반등 에너지를 축적한 모범적인 종목입니다.

## 3. 위험 / 주의 종목 선정 배경
- **CAP (CAP)**: 골든패턴 유사도는 100점으로 높으나, 24시간 변동성이 50.82%에 달해 단기 과열 양상이 매우 심화되어 있습니다. 추격 매수 시 극심한 가격 변동에 노출될 수 있어 철저한 리스크 관리가 필요합니다.

## 4. 최종 투자 전략
단기 과열된 종목은 비중을 축소하고, 골든패턴이 완성되면서 변동성이 제어된 추천 종목 위주로 분할 매수 접근을 권장합니다.
