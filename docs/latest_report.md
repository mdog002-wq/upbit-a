# 퀀트 투자 분석 종합 리포트

## 1. 개요
본 리포트는 최신 퀀트 엔진을 통해 선별된 암호화폐 상위 20개 종목의 거래대금, 24시간 변동성, 골든패턴 유사도 점수를 종합하여 분석한 결과입니다. 시장의 과열 구간과 반등 기대 종목을 엄격하게 필터링하여 투자 전략을 제시합니다.

## 2. 주요 종목 분석
- **추천 종목 (LINK, PRL, AVAX):** 골든패턴 유사도 점수가 100.0으로 역사적 바닥 패턴과 매우 높은 일치율을 보이며, 적절한 변동성 속에서 안정적인 거래대금을 수급하고 있습니다.
- **주의 종목 (CAP):** 24시간 변동성이 50%를 상회하며 과열 양상을 보이고 있어, 단기 투자 시 극도의 리스크 관리가 요구됩니다.
