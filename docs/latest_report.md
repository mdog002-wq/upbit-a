# 암호화폐 퀀트 투자 분석 리포트

## 1. 개요
본 리포트는 제공된 20개 주요 암호화폐 종목의 24시간 거래대금, 변동성, 그리고 골든패턴 유사도 점수를 종합적으로 분석하여 최적의 투자 기회를 포착하고 잠재적 리스크를 관리하기 위해 작성되었습니다.

## 2. 시장 동향 및 퀀트 분석
- **우량주 안정성**: 비트코인(BTC)과 이더리움(ETH)은 높은 거래대금과 함께 골든패턴 점수 100.0점을 기록하며 시장의 중심을 탄탄하게 지키고 있습니다.
- **주목할 만한 알트코인**: 온도(ONDO), 시바이누(SHIB), 그라비티(GRVT) 등은 거래대금과 골든패턴 유사도(100.0점)를 동시에 만족하며 바닥 매집 완료 후 반등 기대감을 높이고 있습니다.
- **주의 구간**: CAP, ONG 등 일부 종목은 30%를 상회하는 극단적인 24시간 변동성을 보여 단기 과열에 따른 급격한 조정 리스크가 존재합니다.

## 3. 투자 전략
- **매수 전략**: 골든패턴 점수가 100.0이면서 상대적으로 변동성이 안정적인 우량 알트코인 위주로 분할 매수 접근을 권장합니다.
- **리스크 관리**: 변동성이 40%를 초과하는 과열 종목은 추격 매수를 자제하고 리스크 관리(손절선 설정)를 엄격히 적용해야 합니다.
